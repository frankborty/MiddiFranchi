# Architecture decisions

This directory contains architecture decision records (ADRs) for MiddiFranchi.

Use one markdown file per decision, named with a sequence number and a short kebab-case title, for
example:

```text
0001-use-postgresql-with-ef-core.md
```

Each record should state the context, the decision, the consequences, and any alternatives that were
considered. Add a new record when a significant architectural choice is made or an existing one is
replaced.
